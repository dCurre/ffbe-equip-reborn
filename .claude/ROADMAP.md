## Bugs and technical debt
- **Persistent login:** old logged-in users must log in once. If Google returns no refresh token (409), the user removes the app at myaccount.google.com/permissions and retries. Optional: rotate the Google client secret (shown once in a session transcript) with `npx wrangler secret put GOOGLE_CLIENT_SECRET` in `worker/`.
- **Extraction tools:** `diffs.exvius.gg`/`diffs.exviusdb.com` are down (2026-11-20): `tools/buildImageLinks`, `tools/JP/getImages.js` and image downloads in `GL|JP/parseItems.js` fail; JSON downloads work. `tools/request.js` is a `fetch` shim.
- **Unused image export helpers:** `elementToPng` and `picturesLoaded` in `src/app/shared/helpers/export.ts` (and the html2canvas loading) lost their only caller when the Units image export was removed; delete them, and the html2canvas dependency or script if nothing else uses it.
- **Builder number fields:** `min="0"` only stops the arrows; a typed negative value is not corrected (the Units edit dialog does clamp).
- **Test coverage:** `npm test` covers formulas, stats/damage, GL golden master, optimizer invariants and reduced-pool goldens. Regenerate goldens only with `npm run test:golden:update`. Gaps: `computeFarmableStmr`, `getItemEntry` with inventory, optimizer owned-only/esper/forced-TMR paths. Reduced-pool goldens don't prove global optimality.

## Features (after the rework)
- **Centralized UI strings:** `src/app/strings/en.ts` (`STRINGS`, one key per area; component: `protected readonly t = STRINGS.<area>`, template: `{{ t.key }}`). All templates and the `title|label|heading|text|tooltip|header|message|placeholder|description|hint` literals and `toast.show('…')` messages in `.ts` files are moved (long sentences with links or variables are split into fragments around them: for a real translation they need whole sentences with placeholders). Left on purpose: the tooltips in `icon-map.ts` (the icon rules keep them beside each icon) and `custom-goal-presets.ts`. Left to do: `name:` literals (slot and stat names, some are data), template literals with `${}` (e.g. `goal.ts` labels), `new Error` texts, and the texts of `src/core`.
- **GitHub wiki (`https://github.com/dCurre/ffbe-equip-reborn/wiki`):** written (Home, Export and import data, Using the builder, Google login and your data). Missing: the steps to export the save from FFBE Offline in "Export and import data" (the link "Export your data from the game" on Units, Inventory and Data import points to that page through `GAME_DATA_URL`). Check on the live wiki that the Google Drive "Manage apps" deletion step and the Parameter challenges text are right.
