## Bugs and technical debt
- **Persistent login:** old logged-in users must log in once. If Google returns no refresh token (409), the user removes the app at myaccount.google.com/permissions and retries. Optional: rotate the Google client secret (shown once in a session transcript) with `npx wrangler secret put GOOGLE_CLIENT_SECRET` in `worker/`.
- **Merged Global + Japan data (`public/ALL`, `tools/mergeServers.js`):** the site reads only `ALL`; GL is the base, JP-only units are "[JP]", a JP version with something more is a second entry `jp-<id>` (`variantOf`). Open: what users saved with the JP server (`*_JP.json` in Drive / local) is not read any more (merge it into the GL set); old links and saved builds with `server=JP` or JP ids; items in both servers keep the GL access (event/TMR); the builder and search of the `[JP]` entries were not seen on screen; the wiki link of a JP-only item or unit may not exist; `ServerContext.server` is always `GL` (the name of the users' Drive files), it could be simplified; `mergeServers.js` runs only with `public/GL|JP` and `tools/GL|JP/sources/units.json` restored from the history (see its header).
- **Missing images and credits:** 19 vision card icons (`vc_vignette_item_icon_*`, `_icon_s_*`, `_anime_*`, ids 1000101…) and the special unit 777700004 Holiday Hero have no picture in any source. The 201 icons, 94 illustrations and `ability_6000500.png` come from `DaddyRaegen/ffbe_asset_dump` (no license file: ask the owner, the README credits it) and `img/icons/NVPlus.png` from the wiki (license not checked). The new JP vision cards have no effect rules (the extraction script warned `Missing rule … 8017, 8018, 8027, 8029, 7952`; the script is gone, add them by hand if needed).
- **NV+ (`nvPlus: true` in the `ALL` unit files; 20 GL + 144 JP units and their Brave Shifts, from the raw `awakening`, checked on 27 units against the wiki):** used by the unit search (max rarity "NV+"), the icons and the builder (level up to 130, equipment cap 600% above level 120: no NV+ switch, the level stands for "enhanced"). Open: the LB level cap 50 (the builder has no LB level), the EX ability slot, the builder list has the text "NV+" only, and the **save import** (waiting for a save to test): the Offline roster has no NV+ field, so read `level` (130 = enhanced) and `lb_level` (up to 50) of the `nvPlus` units; the owner's save has 25 such units, all at level 120. Units that become NV by an awakening from a lower rarity (NVA) are not covered.
- **Unused image export helpers:** `elementToPng` and `picturesLoaded` in `src/app/shared/helpers/export.ts` (and the html2canvas loading) lost their only caller when the Units image export was removed; delete them, and the html2canvas dependency or script if nothing else uses it.
- **Builder number fields:** `min="0"` only stops the arrows; a typed negative value is not corrected (the Units edit dialog does clamp).
- **Test coverage:** `npm test` covers formulas, stats/damage, golden master, optimizer invariants and reduced-pool goldens. Regenerate goldens only with `npm run test:golden:update`. Gaps: `computeFarmableStmr`, `getItemEntry` with inventory, optimizer owned-only/esper/forced-TMR paths. Reduced-pool goldens don't prove global optimality.

## Features (after the rework)
- **Centralized UI strings:** `src/app/strings/en.ts` (`STRINGS`, one key per area; component: `protected readonly t = STRINGS.<area>`, template: `{{ t.key }}`). All templates and the `title|label|heading|text|tooltip|header|message|placeholder|description|hint` literals and `toast.show('…')` messages in `.ts` files are moved (long sentences with links or variables are split into fragments around them: for a real translation they need whole sentences with placeholders). Left on purpose: the tooltips in `icon-map.ts` (the icon rules keep them beside each icon) and `custom-goal-presets.ts`.
